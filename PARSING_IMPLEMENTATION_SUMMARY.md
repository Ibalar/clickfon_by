# Parsing API Implementation Summary

## Обзор

Реализован полноценный API-сервис для управления парсингом цен с других сайтов. Система позволяет автоматически отслеживать цены конкурентов и обновлять цены в базе данных, если найдена более низкая цена.

## Созданные файлы

### 1. `/api/Parsing.php` (36,578 байт)
Основной класс API с полной реализацией всех требуемых методов:

**Управление источниками парсинга:**
- `getSources($filter)` - получение списка источников с фильтрацией
- `getSource($id)` - получение одного источника
- `createSource($data)` - создание источника с валидацией
- `updateSource($id, $data)` - обновление источника
- `deleteSource($id)` - удаление источника (каскадное)

**Управление URL-ами:**
- `importUrls($sourceId, $file, $mode)` - импорт из CSV/TXT с поддержкой 3 режимов
- `getItems($sourceId, $filter)` - получение списка URL-ов с фильтрацией
- `deleteItem($itemId)` - удаление URL

**Парсинг:**
- `parseSource($sourceId)` - основной метод парсинга с полной логикой
- `parseUrl($url, $priceSelector, $articleSelector)` - внутренний метод парсинга HTML
- `testSelector($url, $selector)` - тестирование селектора для админки

**Расписания:**
- `getSchedules($filter)` - получение списка расписаний
- `getSchedule($sourceId)` - получение расписания источника
- `createOrUpdateSchedule($sourceId, $cronExpression)` - создание/обновление расписания
- `deleteSchedule($id)` - удаление расписания
- `checkAndRunSchedules()` - проверка и запуск расписаний
- `getCronNextRun($cronExpression)` - расчет следующего запуска

**Логирование:**
- `getLogs($filter)` - получение логов с мощными фильтрами
- `clearLogs($olderThanDays)` - очистка старых логов
- `createLog($sourceId, $itemId, $action, $message, ...)` - создание записи лога

### 2. `/db_parsing_migration.sql` (5,743 байт)

Все таблицы с каскадными удалениями и оптимизированными индексами.

## Основные возможности

### 1. Полная валидация данных
- Проверка URL-ов (filter_var с FILTER_VALIDATE_URL)
- Проверка обязательных полей
- Валидация артикулов в базе данных (__variants.sku)
- Проверка границ цен (min/max bounds)
- Валидация cron-выражений

### 2. Умное обновление цен
- Цена обновляется **только если спарсенная цена ниже текущей**
- Автоматическое обновление денормализованных полей через `updateProductVariantStats()`
- Логирование старой и новой цены
- Проверка соответствия артикулов

### 3. Импорт URL-ов
Поддержка 3 режимов:
- `create` - только новые записи
- `update` - только существующие
- `create_or_update` - upsert

Поддержка множества форматов файлов:
- CSV (разделители: `,`, `;`)
- TXT с pipe-разделителем (`|`)
- Tab-separated (TSV)

### 4. Парсинг HTML
- Использование библиотеки `sunra/php-simple-html-dom-parser`
- CSS-селекторы для извлечения данных
- Ротация User-Agent (5 вариантов)
- Таймауты (30 сек на URL, 300 сек на источник)
- Rate limiting (1.5 сек между запросами)
- Обработка ошибок и логирование

### 5. Расписания (Cron)
- Поддержка cron-выражений
- Автоматический расчет next_run_at
- Метод для запуска по расписанию
- Логирование всех запусков

### 6. Подробное логирование
Все операции логируются в `__parsing_logs`:
- source_created, source_updated, source_deleted
- urls_imported
- parse_start, parse_item_start, parse_complete
- price_updated (с old_price и new_price)
- schedule_run, schedule_created, schedule_updated
- error (все ошибки)

### 7. Статусы парсинга
Каждый URL имеет статус:
- `pending` - ожидает парсинга
- `parsed` - успешно спарсен
- `error` - ошибка парсинга
- `not_found` - товар не найден в базе

## Интеграция с системой

### Денормализация
При обновлении цены автоматически вызывается:
```php
$this->variants->updateProductVariantStats($variant->product_id);
```

Это обновляет поля в `__products`:
- `min_price` - минимальная цена
- `min_price_currency_id` - валюта минимальной цены
- `has_stock` - наличие на складе
- `has_variants` - наличие вариантов

### Использование через Turbo
```php
require_once 'api/Turbo.php';

$turbo = new Turbo();
$parsing = $turbo->parsing;

// Доступны все методы
$sources = $parsing->getSources(['is_active' => 1]);
```

## Безопасность

1. **SQL Injection защита**: все запросы через `$this->db->placehold()`
2. **Валидация входных данных**: проверка всех параметров
3. **Таймауты**: защита от зависания
4. **Rate limiting**: защита от блокировки IP
5. **User-Agent ротация**: имитация разных браузеров
6. **Каскадное удаление**: через Foreign Keys в БД

## Производительность

1. **Индексы**: оптимизированные индексы на всех таблицах
2. **Лимиты**: пагинация для больших выборок

4. **Очистка логов**: метод для удаления старых записей

## Следующие шаги для полной интеграции

1. **Запустить SQL-миграцию** для создания таблиц
2. **Создать админ-панель** в `/turbo/` для управления парсингом
3. **Настроить cron** для автоматического запуска расписаний
4. **Импортировать первые URL-ы** для тестирования
5. **Запустить первый парсинг** и проверить логи

## Пример быстрого старта

```php
// 1. Создать источник
$sourceId = $parsing->createSource([
    'name' => 'Конкурент XYZ',
    'base_url' => 'https://competitor.com',
    'selector_price' => '.product-price span.amount',
    'selector_article' => '.product-sku',
    'price_min_bound' => 100,
    'price_max_bound' => 50000
]);

// 2. Импортировать URL-ы из файла
$result = $parsing->importUrls($sourceId, '/path/to/urls.csv', 'create');

// 3. Запустить парсинг
$parseResult = $parsing->parseSource($sourceId);

// 4. Настроить автоматический парсинг каждые 6 часов
$parsing->createOrUpdateSchedule($sourceId, '0 */6 * * *');
```

## Архитектурные решения

1. **Не используются MySQL триггеры** - логика в PHP для лучшей переносимости
2. **Денормализация на уровне приложения** - следование существующим паттернам
3. **Композиция через Turbo** - доступ к другим API через `$this->variants`, `$this->db`
4. **Плейсхолдеры для SQL** - безопасность и автоматическая подстановка префикса таблиц
5. **Логирование всех операций** - полная трассируемость для отладки
